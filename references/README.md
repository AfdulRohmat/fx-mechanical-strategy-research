# Reference Manifest

This folder holds lawful open-access or institutional working-paper copies used
to design the research. A local PDF is a convenience copy, not evidence that its
result applies to the present market or implementation.

Do not commit papers obtained through a personal subscription or from an
unauthorized mirror. For paywalled publications, store only the citation, DOI,
official URL, and our own summary.

## Local file integrity

Downloaded files must be listed in `SHA256SUMS.txt`, with the retrieval date and
source URL retained in `DOWNLOADS.md`. A changed upstream file is stored as a
new version; it never silently replaces a cited research artifact.
